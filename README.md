# ClirntCabinet

Личный кабинет для людей, которые **не умеют пользоваться ИИ** и не хотят нанимать программистов. Вместо этого они выбирают готовое решение, отвечают на несколько вопросов, оплачивают его — и получают работающий сайт или автоматизацию.

> Проще, чем n8n: никаких узлов, промптов и API. Только понятные слова и готовые рецепты.

## Что уже есть

- **Личный кабинет:** регистрация, вход, дашборд со статистикой.
- **Каталог решений:** 5 готовых рецептов (сайт + Telegram, AI-звонки, напоминания, автоответ, сбор заявок).
- **Создание сайта:** выбор шаблона и короткая анкета.
- **Счета и оплата:** демо-режим оплаты без списания денег.
- **AI call center (ядро):** сценарии диалога, STT/TTS, адаптеры Twilio и mock, демо-интерфейс.

## Быстрый запуск

```bash
cd ai-call-center
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000 — попадёте на страницу входа. Зарегистрируйтесь и попробуйте подключить любое решение из каталога.

> В этом окружении `python3-venv` отсутствует, поэтому зависимости ставятся так:
> `pip3 install --user --break-system-packages -r ai-call-center/requirements.txt`

## Структура

```text
ai-call-center/
├── app/
│   ├── main.py          # точка входа FastAPI
│   ├── portal.py        # личный кабинет: auth, каталог, счета
│   ├── db.py            # SQLite: пользователи, сайты, сценарии, счета
│   ├── dialogue.py      # сценарии ИИ-диалога (LLM или локальные правила)
│   ├── providers.py     # STT / TTS через OpenAI-совместимый API
│   ├── audio.py         # mu-law ↔ PCM для телефонии
│   ├── templates/       # HTML-страницы кабинета
│   └── static/          # CSS
├── requirements.txt
└── .env.example
```
