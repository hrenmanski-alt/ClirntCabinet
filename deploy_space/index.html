Один промпт → готовый бизнес

Личный кабинет с каталогом готовых решений, созданием сайтов, счетами, AI call-центром и планировщиком, который считает цену и окупаемость.

Открыть демо-кабинет Исходный код на GitHub

Личный кабинет

Готово: вход, дашборд, каталог из 5 решений, создание сайта, счета, демо-оплата. FastAPI + SQLite + Jinja2.

AI call-центр

Готово: диалог на русском, REST + WebSocket + TwiML, аудиоконвейер, STT/TTS, журнал звонков, голосовой виджет в браузере.

Один промпт → бизнес

Готово: план из 9 шагов, поиск инструментов GitHub/Hugging Face, расчёт цены и окупаемости через API.

Утилиты и данные

Готово: бэкап SQLite, экспорт CSV, изоляция пользователей, секреты только в .env.

Внешние интеграции

В работе: реальные звонки Twilio/Novofon, Яндекс Директ и Метрика, Metricool/Telegram/VK, деплой на хостинг.

Статус

Каркас продукта готов. Требуется зарубежный VPS/прокси для LLM, доступы к телефонии и публикациям, мерж feature-веток в main.

Полная схема

Промпт → план → сайт → реклама → соцсети → ИИ-ведущие → звонки → цена и отчёт.

Инфраструктура коротко

Демо-страница на Hugging Face Spaces. Живой кабинет запускается локально: cd ai-call-center && python3 -m uvicorn app.main:app.
Документация: README.md, ARCHITECTURE.md, CALLS.md, NOVOFON.md, VISION.md, PRICING.md, PROXY_SETUP.md.
