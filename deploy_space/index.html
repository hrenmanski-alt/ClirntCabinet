Что уже работает

Каркас продукта собран и проверен тестами. Внешние сервисы подключаются по лимитам и с подтверждениями.

01 // CABINET

Личный кабинет

Готово. Вход, дашборд, каталог из 5 решений, создание сайта, счета и демо-оплата. FastAPI + SQLite + Jinja2.

02 // VOICE

AI call-центр

Готово. Русский диалог, REST + WebSocket + TwiML, mu-law аудио, STT/TTS, журнал звонков и голосовой виджет.

03 // PLANNER

Один промпт → бизнес

Готово. План из 9 шагов, реестр GitHub/Hugging Face, расчёт цены и окупаемости.

04 // DATA

Утилиты

Готово. Бэкап SQLite, CSV-экспорт, изоляция пользователей, секреты только в .env.

05 // CONNECT

Интеграции

В работе. Twilio/Novofon, Яндекс Директ и Метрика, Metricool/Telegram/VK, деплой на хостинг.

06 // DEPLOY

Публикация

В работе. Витрина уже на Hugging Face. Живой кабинет требует VPS/домена или PRO Space.
