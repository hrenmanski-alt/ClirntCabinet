# Яндекс Директ + Яндекс Метрика — ветка `feature/yandex-ads`

## Что будет делать интеграция

1. **Метрика:** создать/подключить счётчик, передать цели (заявка, звонок, покупка), получать статистику.
2. **Директ:** создать кампанию, группу объявлений, объявления и лимит бюджета.
3. **Связка:** цели Метрики используют как цели кампании; данные о заявках из нашего кабинета уходят в Метрику.
4. **Безопасность:** любой запуск кампании и списание денег — только после явного подтверждения клиента.

## Нужные доступы

- Яндекс OAuth-токен с правами `direct` и `metrika`.
- ID клиента Директа и ID счётчика Метрики.
- Лимит дневного бюджета и валюта.

## План реализации

```text
YandexOAuth → DirectService → create_campaign(draft)
                    │
                    └─► MetricaService → goals + hits
                    │
                    ▼
        подтверждение клиента → activate → статистика в кабинете
```

## Статус

Ветка создана, код будет добавляться после получения токенов. Базовый кабинет и колл-центр уже работают в других ветвях.
