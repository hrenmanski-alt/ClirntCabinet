# Вспомогательные инструменты — ветка `feature/utilities`

Здесь лежат «приспособления» — маленькие скрипты, которые помогают поддерживать продукт, но не являются частью самого кабинета.

| Скрипт | Что делает | Запуск |
|--------|------------|--------|
| `tools/draw_scheme.py` | Перерисовывает картинку-схему `docs/scheme.png` | `python3 tools/draw_scheme.py` |
| `tools/export_data.py` | Выгружает таблицы базы в CSV (папка `exports/`) | `python3 tools/export_data.py calls` |
| `tools/backup_db.py` | Делает копию базы с датой в имени (папка `backups/`) | `python3 tools/backup_db.py` |

Папки `exports/` и `backups/` не попадают в git — там могут оказаться данные клиентов.

Планируемые утилиты:
- генератор отчётов по звонкам (конверсия, длительность, результаты);
- импорт базы клиентов из CSV для обзвона;
- проверка доступности сервера и телефонного провайдера.
