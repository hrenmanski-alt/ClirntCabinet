# Соцсети и ИИ-ведущие — ветка `feature/metricool`

## Что планируем

1. Через **Metricool** (или прямой API Telegram/VK) создавать и связывать каналы бизнеса.
2. Готовить контент-план: посты, истории, ответы на комментарии.
3. Назначать несколько ИИ-агентов-ведущих с разными ролями:
   - контент-редактор;
   - ответы на сообщения;
   - аналитик охватов.
4. Все публикации идут в очередь модерации — клиент подтверждает перед выложением.

## Нужные доступы

- Аккаунт Metricool и API-ключ **или** токены Telegram-бота / VK.
- Список соцсетей и страниц.
- Лимиты публикаций и бюджет на рекламу.

## Риски

- платформы меняют API и ограничивают автоматизацию;
- ИИ может написать не то — нужна очередь на проверку;
- весь контент должен соответствовать правилам площадок.

## Статус

Ветка создана. Код появится после выбора конкретного провайдера (Metricool / Telegram / VK) и получения ключей.
